\## 현재 위치와 파일 목록 확인



\### 목적

프로젝트 작업 디렉터리와 숨김 파일을 포함한 목록을 확인한다.



\### 실행 명령과 실제 출력



```console

$ pwd

/home/user/dev-workstation



$ ls -la

total 8

drwxr-xr-x 2 user user 4096 Oct 29 15:26 .

drwxr-x--- 6 user user 4096 Oct 29 15:26 ..

```



\### 결과 해석

\- 프로젝트 작업 디렉터리에 정상적으로 진입했다.

\- 현재 디렉터리에는 아직 별도의 파일이 없다
